# Oxygen contributor agent instructions

When a user asks to collect, organize, review, or package project history:

1. Read `README.md` and `SOP.md`.
2. Use `skills/oxygen-ingest-project-history/SKILL.md` for collection.
3. Use `skills/oxygen-organize-review-export/SKILL.md` for local organization and review.
4. Never read credential files, private keys, tokens, cookies, or system/developer prompts.
5. Keep every output `publication_approved=false` until the user completes review.
6. Never upload or publish automatically. Stop after producing and verifying the downloadable ZIP.
